# 鼠标拖动功能修复说明

## 问题分析

您反映AST可视化不能用键鼠拖动的问题，经过分析发现了根本原因：

### 问题根源
在Swing中，鼠标拖动事件（`mouseDragged`）需要通过 **`MouseMotionListener`** 来监听，而不仅仅是 `MouseListener`。

原来的代码只添加了 `MouseListener`：
```java
addMouseListener(new MouseAdapter() {
    // ... mousePressed, mouseReleased
    @Override
    public void mouseDragged(MouseEvent e) {
        // 这个方法不会被调用！
    }
});
```

### 问题原因
- `MouseListener` 只处理：`mouseClicked`, `mousePressed`, `mouseReleased`, `mouseEntered`, `mouseExited`
- `MouseMotionListener` 才处理：`mouseDragged`, `mouseMoved`
- 虽然 `MouseAdapter` 实现了两个接口，但我们只将它添加为 `MouseListener`

## 修复方案

### 1. 修改事件监听器注册
```java
// 修复前：只添加了MouseListener
addMouseListener(new MouseAdapter() {
    // mouseDragged不会被调用
});

// 修复后：同时添加MouseListener和MouseMotionListener
MouseAdapter mouseHandler = new MouseAdapter() {
    @Override
    public void mousePressed(MouseEvent e) {
        if (SwingUtilities.isLeftMouseButton(e)) {
            lastMousePos = e.getPoint();
            isDragging = true;
            setCursor(Cursor.getPredefinedCursor(Cursor.MOVE_CURSOR));
            
            // 检查是否点击了节点
            ASTNode clickedNode = getNodeAt(e.getPoint());
            if (clickedNode != null) {
                selectedNode = clickedNode;
                repaint();
            }
        }
    }
    
    @Override
    public void mouseReleased(MouseEvent e) {
        if (SwingUtilities.isLeftMouseButton(e)) {
            isDragging = false;
            setCursor(Cursor.getDefaultCursor());
        }
        
        if (SwingUtilities.isRightMouseButton(e)) {
            // 右键显示详细信息
            ASTNode clickedNode = getNodeAt(e.getPoint());
            if (clickedNode != null) {
                showNodeDetails(clickedNode);
            }
        }
    }
    
    @Override
    public void mouseDragged(MouseEvent e) {
        if (isDragging && lastMousePos != null) {
            int deltaX = e.getX() - lastMousePos.x;
            int deltaY = e.getY() - lastMousePos.y;
            
            offsetX += deltaX;
            offsetY += deltaY;
            
            lastMousePos = e.getPoint();
            repaint();
        }
    }
};

// 关键修复：同时添加两个监听器
addMouseListener(mouseHandler);
addMouseMotionListener(mouseHandler);  // 这是关键！
```

### 2. 添加视觉反馈
```java
// 按下时显示移动光标
setCursor(Cursor.getPredefinedCursor(Cursor.MOVE_CURSOR));

// 释放时恢复默认光标
setCursor(Cursor.getDefaultCursor());
```

### 3. 添加必要的import
```java
import java.awt.Cursor;
```

## 技术细节

### Swing事件监听机制
```java
// MouseListener处理的事件
public interface MouseListener extends EventListener {
    public void mouseClicked(MouseEvent e);
    public void mousePressed(MouseEvent e);
    public void mouseReleased(MouseEvent e);
    public void mouseEntered(MouseEvent e);
    public void mouseExited(MouseEvent e);
}

// MouseMotionListener处理的事件
public interface MouseMotionListener extends EventListener {
    public void mouseDragged(MouseEvent e);  // 关键！
    public void mouseMoved(MouseEvent e);
}

// MouseAdapter同时实现了两个接口
public abstract class MouseAdapter 
    implements MouseListener, MouseMotionListener {
    // 但需要分别注册为两种监听器才能生效
}
```

### 拖动算法
```java
// 计算鼠标移动距离
int deltaX = e.getX() - lastMousePos.x;
int deltaY = e.getY() - lastMousePos.y;

// 更新视图偏移量
offsetX += deltaX;
offsetY += deltaY;

// 更新鼠标位置记录
lastMousePos = e.getPoint();

// 重绘界面
repaint();
```
