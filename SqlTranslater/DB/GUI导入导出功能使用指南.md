# SparrowDB GUI 导入导出功能使用指南

## 功能概述

SparrowDB 的图形界面现在支持完整的SQL文件导入导出功能，提供友好的用户界面来管理数据库的备份、恢复和批量操作。

## 新增功能

### 🎯 菜单栏功能

在GUI界面顶部新增了"文件"菜单，包含以下功能：

1. **导入SQL文件...** - 从文件导入并执行SQL语句
2. **导出数据库...** - 将整个数据库导出为SQL文件
3. **导出单个表...** - 将指定表导出为SQL文件
4. **批量导入目录...** - 从目录批量导入SQL文件

## 详细使用说明

### 1. 导入SQL文件

**操作步骤：**
1. 点击菜单 "文件" → "导入SQL文件..."
2. 在文件选择对话框中选择要导入的.sql文件
3. 选择执行模式：
   - **是**：容错模式（遇到错误时跳过并继续执行后续语句）
   - **否**：快速失败模式（遇到第一个错误时停止执行）
4. 点击确定开始导入

**功能特性：**
- 自动解析多条SQL语句
- 移除SQL注释（单行和多行）
- 提供详细的执行结果反馈
- 支持容错模式和快速失败模式
- 实时显示导入进度和状态

### 2. 导出数据库

**操作步骤：**
1. 点击菜单 "文件" → "导出数据库..."
2. 选择保存位置和文件名（默认：database_backup.sql）
3. 在导出选项对话框中配置：
   - ☑️ **包含表结构**：导出CREATE TABLE语句
   - ☑️ **包含数据**：导出INSERT语句
   - **指定表（可选）**：留空导出所有表，或用逗号分隔指定表名
4. 点击确定开始导出

**导出选项说明：**
- **表结构 + 数据**：完整的数据库备份
- **仅表结构**：只导出CREATE TABLE语句
- **仅数据**：只导出INSERT语句
- **指定表**：可以选择性导出某些表，如："users,products,orders"

### 3. 导出单个表

**操作步骤：**
1. 点击菜单 "文件" → "导出单个表..."
2. 从下拉列表中选择要导出的表
3. 选择保存位置和文件名（默认：表名_backup.sql）
4. 点击确定开始导出

**特点：**
- 自动获取数据库中的所有表名
- 默认同时导出表结构和数据
- 生成的文件可以独立使用

### 4. 批量导入目录

**操作步骤：**
1. 点击菜单 "文件" → "批量导入目录..."
2. 选择包含SQL文件的目录
3. 输入文件名模式（默认：*.sql）
   - 例如：`*.sql`、`script_*.sql`、`backup*.sql`
4. 选择执行模式（容错或快速失败）
5. 点击确定开始批量导入

**功能特性：**
- 支持文件名模式匹配
- 按文件名字母顺序执行
- 提供批量处理进度报告
- 支持容错模式处理大量文件

## 界面特性

### 🎨 用户体验

1. **状态指示器**
   - 实时显示操作状态（正在导入/导出/成功/失败）
   - 不同颜色表示不同状态（蓝色=进行中，绿色=成功，红色=失败）

2. **结果反馈**
   - 在主界面的结果标签页中显示详细信息
   - 包含操作摘要、执行时间、成功/失败统计

3. **文件过滤**
   - 文件选择对话框自动过滤.sql文件
   - 自动添加.sql扩展名

4. **覆盖保护**
   - 导出文件存在时询问是否覆盖
   - 防止意外覆盖重要文件

### 🔧 高级选项

1. **导出配置对话框**
   - 灵活的导出选项组合
   - 智能验证（确保至少选择一个选项）
   - 指定表名支持（逗号分隔）

2. **错误处理**
   - 友好的错误消息显示
   - 详细的错误信息帮助排错
   - 操作失败时的回滚机制

## 使用示例

### 示例1：完整数据库备份

1. 点击 "文件" → "导出数据库..."
2. 保存为 "my_database_backup.sql"
3. 勾选 "包含表结构" 和 "包含数据"
4. 指定表留空（导出所有表）
5. 确定导出

### 示例2：导入测试数据

1. 点击 "文件" → "导入SQL文件..."
2. 选择 "test_data.sql"
3. 选择 "是"（容错模式）
4. 开始导入

### 示例3：批量处理SQL脚本

1. 点击 "文件" → "批量导入目录..."
2. 选择包含多个SQL文件的文件夹
3. 文件模式输入 "init_*.sql"
4. 选择容错模式
5. 开始批量导入

## 快捷提示

### 💡 最佳实践

1. **定期备份**：使用"导出数据库"功能定期创建完整备份
2. **测试恢复**：在重要操作前先在测试环境验证SQL文件
3. **命名规范**：使用有意义的文件名，包含时间戳
4. **分批处理**：对于大型数据库，考虑分表导出
5. **版本控制**：将重要的SQL脚本纳入版本控制

### ⚠️ 注意事项

1. **文件编码**：确保SQL文件使用UTF-8编码
2. **权限检查**：确保有读取源文件和写入目标文件的权限
3. **磁盘空间**：大型数据库导出前检查可用磁盘空间
4. **事务处理**：每条SQL语句在独立事务中执行
5. **数据一致性**：导入前建议先备份现有数据

## 键盘快捷键

当前版本支持的快捷键：
- **F5**：执行选中的SQL语句
- **F9**：执行全部SQL语句
- **Ctrl+Enter**：执行全部SQL语句
- **Ctrl+Space**：SQL自动补全

## 技术信息

### 支持的文件格式
- **.sql** - 标准SQL文件
- **UTF-8编码** - 支持中文和特殊字符
- **多语句文件** - 自动分离分号分隔的语句

### 执行模式
- **同步执行** - 按顺序逐条执行SQL语句
- **事务隔离** - 每条语句独立事务
- **错误回滚** - 支持操作失败时的自动回滚

### 性能特点
- **流式处理** - 支持大文件导入导出
- **进度反馈** - 实时显示处理进度
- **内存优化** - 避免大文件导致的内存问题

通过这些新功能，SparrowDB 的GUI界面现在提供了完整的数据库管理体验，让数据的导入导出变得简单直观。无论是日常的数据备份还是复杂的数据迁移任务，都可以通过友好的图形界面轻松完成。
