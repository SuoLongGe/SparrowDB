# SparrowDB GUI 右键导出功能使用说明

## 📋 功能概述

新增的右键导出功能允许用户直接在数据库树中右击表名，快速导出表数据到指定位置，支持多种格式。

## 🎯 主要特性

### ✅ 支持的导出格式
- **SQL** - 导出为可执行的SQL语句，包含表结构和数据
- **CSV** - 导出为逗号分隔值文件，适合在Excel等工具中打开
- **JSON** - 导出为JSON格式，便于Web应用和API使用

### ✅ 右键菜单选项
- **显示表数据** - 在查询窗口中显示表的所有数据
- **导出表** - 弹出导出对话框，选择格式和保存位置
- **删除表** - 删除选中的表（需要确认）

## 🔧 使用步骤

### 1. 启动GUI界面
```bash
cd SqlTranslater/DB
java -cp target/classes com.sqlcompiler.DatabaseGUI
```

### 2. 查看数据库表
- 在左侧的"数据库对象"面板中，可以看到"表"节点
- 展开"表"节点，显示所有可用的数据表

### 3. 右键导出表
1. **右击表名** - 在任意表名上右击鼠标
2. **选择导出表** - 从弹出的上下文菜单中选择"导出表"
3. **选择格式** - 在弹出对话框中选择导出格式（SQL/CSV/JSON）
4. **选择位置** - 选择保存文件的位置和文件名
5. **确认导出** - 点击"保存"按钮开始导出

## 📁 导出格式详细说明

### SQL格式导出
- **包含内容**：表结构定义 + 数据插入语句
- **适用场景**：数据备份、数据迁移、数据库复制
- **文件扩展名**：`.sql`
- **特点**：可直接在其他数据库中执行恢复数据

### CSV格式导出
- **包含内容**：列标题 + 数据行（逗号分隔）
- **适用场景**：数据分析、Excel处理、数据交换
- **文件扩展名**：`.csv`
- **特点**：
  - 使用UTF-8编码，支持中文
  - 自动处理包含逗号和引号的字段
  - 首行为列名标题

### JSON格式导出
- **包含内容**：表元数据 + 结构化数据
- **适用场景**：Web应用、API数据、NoSQL数据库
- **文件扩展名**：`.json`
- **特点**：
  - 包含表名和导出时间信息
  - 结构化数据，易于程序处理
  - 自动处理字符转义

## 🎨 导出文件示例

### CSV格式示例
```csv
"customer_id","first_name","last_name","email","city"
1,"张","三","zhang.san@email.com","北京"
2,"李","四","li.si@email.com","上海"
3,"王","五","wang.wu@email.com","广州"
```

### JSON格式示例
```json
{
  "tableName": "customers",
  "exportTime": "2025-09-15T14:30:45.123",
  "columns": ["customer_id", "first_name", "last_name", "email", "city"],

    {
      "customer_id": 1,
      "first_name": "张",
      "last_name": "三",
      "email": "zhang.san@email.com",
      "city": "北京"
    },
    {
      "customer_id": 2,
      "first_name": "李",
      "last_name": "四",
      "email": "li.si@email.com",
      "city": "上海"
    }
  ]
}
```

## ⚠️ 注意事项

1. **文件覆盖**：如果选择的文件已存在，系统会提示是否覆盖
2. **大数据量**：导出大表时可能需要较长时间，请耐心等待
3. **编码格式**：所有导出文件都使用UTF-8编码，确保中文正确显示
4. **权限要求**：确保对选择的导出目录有写入权限
5. **表结构**：CSV和JSON导出依赖表的元数据信息

## 🚀 功能优势

- **用户友好**：直观的右键操作，无需记忆命令
- **格式丰富**：支持三种主流数据格式
- **自动处理**：自动处理特殊字符和数据类型
- **元数据保护**：JSON格式包含完整的表结构信息
- **错误处理**：完善的错误提示和状态反馈

## 🔧 故障排除

### 导出失败
1. 检查文件路径是否有效
2. 确认对目标目录有写入权限
3. 检查表是否包含数据
4. 查看状态栏的错误信息

### 数据显示异常
1. 确认表结构定义正确
2. 检查数据编码是否为UTF-8
3. 验证数据类型是否兼容

### 右键菜单未显示
1. 确认右击的是表节点而不是其他节点
2. 检查表是否正确加载到数据库树中
3. 尝试刷新数据库树
