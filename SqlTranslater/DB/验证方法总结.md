# SparrowDB 视图和函数功能验证方法总结

## 🎯 验证目标
确认SparrowDB数据库系统中的视图和函数功能完全正常工作。

## 🚀 三种验证方式

### 方式1: GUI界面验证 (推荐用于交互式测试)

#### 启动方法：
```batch
# 双击运行批处理文件
run_gui.bat

# 或在命令行执行
call run_gui.bat
```

#### 验证步骤：
1. **启动GUI** - 观察数据库连接状态
2. **复制测试SQL** - 从`GUI测试用例.sql`文件复制SQL语句
3. **执行测试** - 使用以下方式执行：
   - 粘贴SQL后点击"执行SQL"按钮
   - 选中部分SQL后按F5执行选中内容  
   - 按F9或Ctrl+Enter执行全部SQL
4. **观察结果** - 检查四个区域的显示：
   - **执行结果区域**: SQL执行结果和错误信息
   - **Token列表**: 词法分析结果
   - **AST可视化**: 语法树图形显示
   - **状态栏**: 执行状态和耗时

#### GUI验证重点：
- ✅ 语法高亮正常显示
- ✅ 函数Token正确识别
- ✅ AST结构正确生成
- ✅ 执行结果准确显示
- ✅ 错误处理清晰明确

### 方式2: 命令行应用验证 (推荐用于系统测试)

#### 启动方法：
```batch
# 编译并运行
javac -encoding UTF-8 -cp "target/classes" -d target/classes src/main/java/com/database/SparrowDBApplication.java
java -cp "target/classes" com.database.SparrowDBApplication
```

#### 验证命令：
```bash
# 进入应用后，使用以下专门的测试命令：

# 查看帮助
help

# 查看示例（包含函数和视图示例）
examples

# 专门的函数测试
test functions

# 专门的视图测试  
test views

# 综合功能测试
test all

# 查看现有表
tables

# 手动执行SQL测试
SELECT UPPER(name) FROM users;
CREATE VIEW test_view AS SELECT * FROM users WHERE age > 25;
DROP VIEW test_view;
```

#### 命令行验证重点：
- ✅ 自动化测试通过率
- ✅ 交互式命令响应
- ✅ 结果格式化显示
- ✅ 性能统计准确
- ✅ 数据持久化正常

### 方式3: 批处理验证工具 (推荐用于快速验证)

#### 启动方法：
```batch
# 双击运行验证工具
验证视图和函数功能.bat
```

#### 验证选项：
1. **启动GUI界面** - 跳转到GUI验证
2. **启动命令行应用** - 跳转到命令行验证
3. **运行自动化测试** - 执行快速自动测试
4. **查看验证指南** - 显示详细指南
5. **退出** - 结束验证

## 🎯 快速验证流程 (5分钟)

1. **启动验证工具** (30秒)
   ```batch
   验证视图和函数功能.bat
   ```

2. **选择GUI验证** (30秒)
   - 选择选项1启动GUI

3. **执行核心测试** (3分钟)
   ```sql
   -- 复制粘贴到GUI执行
   SELECT ABS(-5), UPPER('hello'), LENGTH('test') FROM users LIMIT 1;
   CREATE VIEW test_v AS SELECT name FROM users;
   DROP VIEW test_v;
   ```

4. **检查结果** (1分钟)
   - 执行结果正确
   - AST显示正常
   - 无错误信息

5. **得出结论** (30秒)
   - 功能正常 ✅
   - 需要修复 ❌

通过以上三种验证方式，你可以全面、快速、准确地验证SparrowDB的视图和函数功能！
