### 🔗 视图与函数结合验证

#### 复合功能测试
```sql
-- 测试20: 在视图中使用数学函数
CREATE VIEW employee_summary AS 
SELECT 
    UPPER(name) AS employee_name, 
    department, 
    ROUND(salary / 12, 2) AS monthly_salary,
    ABS(salary - 70000) AS salary_diff
FROM employees;

-- 测试21: 在视图中使用字符串函数
CREATE VIEW formatted_products AS 
SELECT 
    CONCAT(name, ' (', category, ')') AS product_info, 
    ROUND(price, 2) AS rounded_price
FROM products;

-- 测试22: 复杂视图与函数结合
CREATE VIEW employee_analysis AS 
SELECT 
    CONCAT(UPPER(name), ' - ', department) AS employee_info,
    salary,
    ROUND(salary / 12, 2) AS monthly_salary,
    CASE 
        WHEN salary > 75000 THEN 'High'
        WHEN salary > 65000 THEN 'Medium' 
        ELSE 'Low'
    END AS salary_level
FROM employees;
```

## 🐛 常见问题排查

### DROP TABLE 错误处理
```sql
-- ❌ 错误：当前系统不支持 DROP TABLE
-- DROP TABLE products;

-- ✅ 正确：删除表中所有数据
DELETE FROM products;

-- ✅ 正确：如果是视图，可以删除视图
DROP VIEW IF EXISTS view_name;
```

**说明**：当前 SparrowDB 系统只实现了 `DROP VIEW` 功能，暂不支持 `DROP TABLE`。如果需要清空表数据，请使用 `DELETE FROM table_name;`

### 编译问题
```batch
# 如果遇到编码问题，确保使用UTF-8编译
javac -encoding UTF-8 -cp "target/classes" -d target/classes *.java
```

### 运行时问题
1. **找不到主类**: 检查classpath设置
2. **数据库初始化失败**: 检查data目录权限
3. **函数不识别**: 检查TokenType和语法分析器
4. **视图操作失败**: 检查ViewManager实现

### 功能验证失败
1. **函数计算错误**: 检查FunctionEvaluator实现
2. **视图查询失败**: 检查视图重写逻辑
3. **数据不持久**: 检查StorageAdapter配置
